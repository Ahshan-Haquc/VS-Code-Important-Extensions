📦 VS Code Important Extensions
প্রতিটি Web Developer এর জন্য গুরুত্বপূর্ণ কিছু Visual Studio Code এক্সটেনশনের তালিকা ও ব্যবহারের উদ্দেশ্য নিচে দেওয়া হলো:

✅ Auto Close Tag
👉 HTML/JSX ট্যাগ লিখলে স্বয়ংক্রিয়ভাবে বন্ধ ট্যাগ লিখে দেয়।

✅ Auto Rename Tag
👉 একটি ট্যাগের নাম পরিবর্তন করলে ওপেন ও ক্লোজ ট্যাগ — দুইটাই একসাথে পরিবর্তন হয়।

✅ Code Runner
👉 ছোট JavaScript, Python বা অন্য কোড স্নিপেট দ্রুত রান করার জন্য।

✅ GitHub Copilot
👉 AI দিয়ে স্বয়ংক্রিয়ভাবে কোড সাজেশন বা অটো-কমপ্লিশন দেয় (OpenAI Powered)।

✅ GitHub Copilot Chat
👉 AI সহকারী হিসেবে চ্যাট ইন্টারফেসে কোড ব্যাখ্যা, পরিবর্তন বা বোঝাতে সাহায্য করে।

✅ npm Intellisense
👉 import করার সময় npm প্যাকেজগুলোর নাম সাজেস্ট করে এবং দ্রুত ইমপোর্টে সাহায্য করে।

✅ Path Intellisense
👉 ফাইল ইমপোর্ট করার সময় সঠিক path suggestion দেখায়।

✅ Reactjs Code Snippets
👉 React.js এর জন্য সাধারণ component, hooks ইত্যাদির স্নিপেট দিয়ে কোডিং দ্রুত করে।

✅ VSCode React Refactor
👉 React component গুলো সহজে extract করে নতুন ফাইলে রিফ্যাক্টর করতে সাহায্য করে।

✅ Tailwind CSS IntelliSense
👉 Tailwind CSS class টাইপ করার সময় auto-complete ও preview দেখায়।

✅ Auto Import - ES6, TS, JSX, TSX
👉 Variable বা Function লিখলে যদি সেটি অন্য ফাইলে থাকে, তাহলে স্বয়ংক্রিয়ভাবে import লাইন যোগ করে।

✅ ESLint
👉 JavaScript কোডে ভুল বা warning ধরিয়ে দেয় এবং কোড কনসিস্টেন্সি বজায় রাখে।

✅ Prettier - Code Formatter
👉 কোডকে নির্দিষ্ট format অনুযায়ী সুন্দর করে সাজিয়ে দেয় (auto indent, spacing etc)।

✅ Stylelint
👉 CSS/SASS ইত্যাদি কোডে lint checker এর মতো ভুল ধরায় এবং clean কোড লিখতে সাহায্য করে।

✅ vscode-icons
👉 Explorer প্যানেলে প্রতিটি ফাইল টাইপ অনুযায়ী সুন্দর আইকন দেখায়।
